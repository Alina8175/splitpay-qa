# SplitPay

Совместный учёт общих расходов: группы, расходы с разными способами деления,
автоматический расчёт долгов, отметка долга оплаченным и история операций.

Только Node.js и встроенные модули — никаких зависимостей, `npm install` не нужен.

## Запуск

```
node app/server.js
```

Затем откройте http://127.0.0.1:3000

Переменные окружения (необязательно): `PORT` (по умолчанию 3000), `HOST`
(по умолчанию 127.0.0.1), `SPLITPAY_DATA` (путь к файлу данных).

## Данные

Всё хранится в JSON-файле `app/data.json`, он создаётся автоматически при первом запуске.
Запись атомарная (через временный файл + rename).

## Как пользоваться

1. Зарегистрируйте аккаунт (email + пароль).
2. Создайте группу. Добавлять в неё можно только уже зарегистрированных пользователей — по email.
3. Добавляйте расходы: сумма, валюта, плательщик, категория и список участников.
   Делить можно **поровну**, **по процентам** или **вручную** (точные суммы).
4. Вкладка «Долги» показывает баланс каждого участника и минимальный список переводов
   «кто кому сколько должен» — отдельно по каждой валюте.
5. Кнопка «Оплачен» отмечает долг погашенным; отметку можно отменить.
6. Вкладка «История» — журнал всех операций группы.

Пользователь видит только те группы, в которых он состоит: запрос чужой группы
возвращает 404, чтобы нельзя было даже узнать о её существовании.

## Устройство

```
app/
  server.js          HTTP-сервер, маршрутизация, отдача статики
  lib/store.js       загрузка/сохранение JSON-файла
  lib/util.js        деньги (целые копейки), деление сумм, валидация
  lib/auth.js        регистрация, вход, сессии (scrypt + токен)
  lib/balances.js    расчёт балансов и упрощение долгов
  lib/api.js         обработчики API
  public/            HTML/CSS/JS интерфейса
```

Все суммы хранятся в целых копейках, поэтому при делении не возникает потерь:
остаток от деления раздаётся по одной копейке первым участникам, а сумма долей
всегда точно равна сумме расхода.

## API

Аутентификация: заголовок `Authorization: Bearer <token>` или cookie `splitpay_token`
(выдаётся при входе).

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register` | регистрация `{name, email, password}` |
| POST | `/api/auth/login` | вход `{email, password}` |
| POST | `/api/auth/logout` | выход |
| GET | `/api/me` | текущий пользователь |
| GET | `/api/meta` | список категорий и способов деления |
| GET | `/api/groups` | мои группы + мой баланс по каждой |
| POST | `/api/groups` | создать `{name, description, currency, memberEmails[]}` |
| GET | `/api/groups/:id` | группа целиком: расходы, балансы, долги, история |
| PATCH | `/api/groups/:id` | изменить название/описание/валюту |
| DELETE | `/api/groups/:id` | удалить группу (только создатель) |
| POST | `/api/groups/:id/members` | добавить участника `{email}` |
| DELETE | `/api/groups/:id/members/:userId` | убрать участника |
| GET | `/api/groups/:id/expenses` | расходы, фильтры `?category=&payerId=&currency=` |
| POST | `/api/groups/:id/expenses` | добавить расход |
| PUT | `/api/groups/:id/expenses/:expenseId` | изменить расход |
| DELETE | `/api/groups/:id/expenses/:expenseId` | удалить расход |
| GET | `/api/groups/:id/balances` | балансы и долги по валютам |
| POST | `/api/groups/:id/settlements` | отметить долг оплаченным |
| DELETE | `/api/groups/:id/settlements/:settlementId` | отменить отметку |
| GET | `/api/groups/:id/activity` | история операций `?limit=` |

Пример добавления расхода:

```json
{
  "description": "Ужин",
  "amount": "3000.00",
  "currency": "RUB",
  "category": "Кафе и рестораны",
  "payerId": "usr_...",
  "splitType": "percent",
  "splits": [
    { "userId": "usr_a", "value": 50 },
    { "userId": "usr_b", "value": 30 },
    { "userId": "usr_c", "value": 20 }
  ]
}
```

Для `splitType: "equal"` достаточно передать `participants: ["usr_a", "usr_b"]`,
для `"manual"` — `splits` с точными суммами (их сумма должна совпасть с суммой расхода).
