# Список мусора на удаление вручную

Составлен 28 августа 2026, перед сдачей. **Ничего не удалено:** среда
на машине владельца возвращает `Operation not permitted` на `rm` внутри
подключённой папки (риск Р-1), а инструмента запроса права на удаление
в этой сборке нет. Убирает владелец, руками.

Все перечисленное **в репозиторий не входит** — проверено `git check-ignore`
после правки `.gitignore` от 28 августа. То есть это мусор на диске,
а не в сдаче.

## Порядок

```
rm -f  evidence/hook-demo.txt _do-git-steps.sh
rm -rf _transfer/ _pending/
rm -rf .git/_trash/
```

Если среда откажет на `rm` — перенести в `_to_delete/` и удалить оттуда
проводником. `_to_delete/` внесён в `.gitignore` 28 августа.

## Проверить после уборки

```
git status --short          # пусто = чисто
git check-ignore -v 04*.md 04*.pdf 05*.md 05*.pdf
```

Вторая команда обязательна: она подтверждает, что материалы курса
действительно игнорируются. Из облачной сессии это проверить было нечем —
файловый мост вернул имена файлов в испорченной кодировке. Разбор —
`evidence/secrets-scan.md`.
