## Решения, принятые в этой сессии

| Решение | Основание |
|---|---|
| Приложение пишет отдельный субагент с чистым контекстом | Автор и проверяющий не должны быть одним контекстом |
| Код приложения не читаем и не правим | Тестируем как чужое, по наблюдаемому поведению |
| Файлы-заготовки не создаются | Либо файл заполнен, либо его нет |
| Пустые каталоги не коммитятся, `.gitkeep` не создаётся | `.gitkeep` — та же заготовка |
| Инструкции запуска в README откладываются до появления приложения | Писать было бы нечего |
| Ни один шаг не зависит от `npm install` | Реестр npm недоступен (E403) |
| UI-проверки — только в облачном контейнере | Playwright есть только там |
